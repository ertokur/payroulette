# PayRoulette

Колесо фортуны, которое решает, кто закрывает счёт в баре и забирает кэшбек.

Это PWA: откройте сайт на телефоне и добавьте его на главный экран.
- **Android (Chrome):** меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- **iOS (Safari):** «Поделиться» → «На экран „Домой“».

Иконки генерируются скриптом `node tools/gen-icons.js`.
